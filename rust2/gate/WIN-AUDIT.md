# Gate win-class audit — WIN-AUDIT.md

`win` cases gate only Rust-vs-C++ exit status; stdout is recorded
but never compared anywhere in the gate. This audit diffs those
bytes so the win class cannot become a silent black hole.
Generated by `python gate/qc_win_audit.py`; re-run after any
command-lane change to a win-heavy command.

Classifications: **aligned** (byte-equal), **wording** (equal after
normalizing brand/path/line-ending/whitespace — demote-to-note
candidates for the command lane), **structural** (normalized bodies
still differ — human review), **probe-fail** (harness error).
