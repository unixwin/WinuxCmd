# Help-surface sweep — HELP-SURFACE.md

Every implemented command (the 47 gen-cases collect() tables) x
`--help` / `--version` / `-h` / `--bogus`, rust2 driver vs GNU
coreutils 9.4 (WSL oracle, batched per-command scratch
`/tmp/winuxcmd-gate-qc-help`). Generated by
`python gate/qc_help_surface.py`.

Driver provenance: `drivers: rust=D:\repo\wc-20inv\rust2\target\debug\winuxcmd-driver.exe; cpp=D:\repo\wc-20inv\rust2\..\build-vs\usr\bin\winuxcmd.exe; bash(setup)=C:\Users\cmx\AppData\Local\Programs\Niubash\winuxcmd\usr\bin\bash.EXE; gnu=WSL /usr/bin coreutils`

The #1563 class (13 commands with empty --help/--version) and the
#1550 pilot bug (`false --help` rc 0) are the failure modes this
sweep exists to catch: EMPTY-HELP is the empty-output regression,
RC-ONLY is a silent status flip on the help/usage path.
