# gate/cases-posix/ — shell-namespace (POSIX-spelling) case tables

Hand-maintained skeletons (NOT generated by `gate/gen-cases.py`, which owns
`gate/cases/` only). Run with:

    bash gate/run-gate.sh --posix-mode            # pending-tolerant
    POSIX_STRICT=1 bash gate/run-gate.sh --posix-mode   # hard-gated (post-port)

Contract under test: rubash hands its own applets POSIX spellings verbatim
(niubash#346 boundary) and the applets resolve them through the shell
namespace — `src/utils/native_path.cppm:shell_tree_map_w`: `/tmp` and
`/var/tmp` to TMPDIR, `/home` to HOME's parent, `/mnt/X` to drive X, bare `/`
and everything else to the configured install root
(`__RUBASH_SHELL_ROOT` > `NIU_ROOT` > `WINUXSH_ROOT` > `RUBASH_ROOT`), with
`/usr/bin/X` folding to `X.exe`. The `--posix-mode` fixture sets
`__RUBASH_SHELL_ROOT`, `TMPDIR`, `HOME` (see run-gate.sh header).

Row modes:

- `posix`      — strict comparison (stdout bytes + rc vs GNU), but failures
                 count as PENDING, not FAIL, until the native_path Rust port
                 (`winux-core/path.rs`) lands. `POSIX_STRICT=1` gates them.
- `posix-exit` — same pending semantics, rc-only comparison (for outputs that
                 print absolute paths and are platform-form-bound forever).
- `strict`     — hard gate even in posix-mode: string-only spellings
                 (basename/dirname) that must already pass byte-for-byte.
                 A failing `strict` control fails the run — it means the
                 harness, not the port, is broken.

Setup column convention (posix-mode): a `;`-separated list of simple applet
invocations, run THROUGH THE SIDE'S OWN EXE so the mapper under test
materializes the fixture (rubash drives its coreutils; so do we). No quotes,
redirections, pipes, or shell builtins. GNU always runs setup as plain sh
(native oracle). Setup through the driver failing pre-port is itself the
pending signal — the gated case then errs on the missing file.

GNU-side sandbox prefixes (cleaned after each case): `/tmp/winuxcmd-gate-posix`,
`/var/tmp/winuxcmd-gate-posix`, `/home/winuxcmd-gate`. Never spell a write
outside these on the GNU side; `/mnt/c` cases are read-only probes.
