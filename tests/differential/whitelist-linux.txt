Passes in the native runner shape, where the export reaches the subject; the applet itself honours LC_ALL (src/commands/locale.cpp)
corpus/updatedb/01-silent-success.case	environment: the WSL image's GNU updatedb.sh cannot run at all in the baseline job - it aborts with "updatedb needs to be able to execute '/usr/libexec/frcode', but cannot" (exit 1) because the image does not provide an executable frcode at the path the script was configured with (evidenced from the baseline job log, run 41213512747, where the subject side silently exits 0 and writes the correct 224-byte database). The subject's silent-success shape is the GNU contract and is pinned natively by the updatedb unit tests.
