> 用途：WP-S 发布时的 README banner、Release 公告、短公告。所有数字与
> 行为声明都以 `DOCS/2.0-MIGRATION.md` / `DOCS/2.0-RELEASE-NOTES.md` /
> `rust2/GATE-REPORT.md` 为准；发布前逐条复核，**不写无法引用的性能数字、
> 不写"完全兼容 GNU"**。

## 2. Release 公告（GitHub Release 首段）

**EN**

> WinuxCmd 2.0.0 moves the command core to a library-form Rust implementation.
> It is an implementation release: the 176-command surface, the multicall
> binary, the help text, the editions and WPM are the same. What changed is
> what runs underneath — injected IO, explicit environment and cwd, no
> process-global state, one static-linked image, and a three-way
> differential gate against GNU for every wired applet.
>
> It is not a claim that every applet is Rust yet. 50 are wired, 32 more are
> gate-green and queued, and the rest keep the 1.x core until their wave.
> `DOCS/2.0-inventory.tsv` is the per-command truth, and
> `DOCS/2.0-MIGRATION.md` lists every user-visible change, including the
> retired 1.x-only options.

**中**

> WinuxCmd 2.0.0 把命令核心换成库形态的 Rust 实现。这是一次实现层换代：
> 176 个命令的面、multicall 二进制、帮助文本、edition 与 WPM 都不变；
> 变的是底下跑的东西——显式注入 IO、显式环境与 cwd、无进程全局状态、
> 单镜像静态链接，以及每个接线 applet 的三方 GNU 差分门。
>
> 这不等于"所有 applet 都已换成 Rust"。50 个已接线，32 个差分门全绿待接线，
> 其余在轮到之前保持 1.x 核心。逐命令真相在 `DOCS/2.0-inventory.tsv`，
> 所有用户可见变化（含退役的 1.x 私有选项）在 `DOCS/2.0-MIGRATION.md`。

## 4. 不能说的话（发布前自检）

| 不要说 | 为什么 | 可以说 |
|---|---|---|
| "完全兼容 GNU" / "100% GNU" | 存在分类过的平台子集与 win/note 行 | "设门面逐字节对照 GNU；每条剩余差异有分类" |
| "全部 176 个命令已用 Rust 重写" | 快照时 50 接线 / 32 待接线 / 91 仍 1.x | "50 个已接线，32 个待接线，逐命令状态见清点表" |
| "比 GNU 快" | 只有 sort 的受控基准，且平台不可比 | "sort 在 64 MiB NTFS 基准上比 1.x C++ 快 12 倍" |
| "零依赖" | PCRE2 是钉死的静态原生依赖 | "无运行时依赖；PCRE2 静态链接、版本钉死" |
| "删掉了 C++" | 保留面（grep -P、注册壳、调度器、wpm）仍在 | "C++ 主体按命令退役，保留面有文档锚点" |
| "修复了所有已知 bug" | #1639–#1657 等仍开放 | "每条已修差异有 gate 行；未修项按 issue 跟踪" |
