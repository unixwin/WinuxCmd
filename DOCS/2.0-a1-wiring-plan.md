### 4.2 dispatch 函数 / CMake 并集

10 个 A1 命令同构：保留 `REGISTER_COMMAND`、`*_OPTIONS`、help/description/
examples，删 C++ 体，函数体只留：

```cpp
return winux::rust2::run_command("<name>", ctx.raw_args);
```

无一读 stdin（`nice`/`runcon` 通过 childproc 起子进程，不进
`kRust2StdinCommands`；`mkfifo/mknod` 是 FIFO marker 面）。
`CMakeLists.txt` 的 `WINUXCMD_RUST2_COMMANDS` 并集（排序）：

```cmake
set(WINUXCMD_RUST2_COMMANDS "arch;b2sum;base32;base64;basename;dirname;echo;expand;false;fmt;fold;getconf;groups;hostid;hostname;id;join;ln;md5sum;mkdir;mkfifo;mknod;mktemp;nice;nproc;numfmt;paste;pathchk;pinky;printenv;pwd;readlink;realpath;rev;rmdir;runcon;seq;sha1sum;sha224sum;sha256sum;sha384sum;sha512sum;sleep;stat;sync;tac;tee;test;test_bracket;timeout;touch;true;truncate;tsort;uname;unexpand;unlink;users;who;whoami")
```

根据源码常量/选项表与 bridge 的 `rust2_reads_stdin` 均无需改。
旧草案里 help/version 的 `strict→win` 批量降级**不得**照搬：`arch --help/--version`
实测与 GNU 逐字节相同（driver `arch --help` vs WSL `/usr/bin/arch --help`），
gate 现有 strict 行已绿；降级会让门失去约束。
