## 六、探针方法论（重要）

**agent bash 是 niubash 系**——会改写 POSIX 参数，`MSYS_NO_PATHCONV` 和 `MSYS2_ARG_CONV_EXCL` 均无效（实测记录）。

正确探针通道：

## 八、合并纪律（ captain 专用）

- Agents **不自合并**——报告文件清单+验证结果，captain 审后 commit/push/merge
- 推送验证用 `ls-remote` 不用 "up-to-date"（多 worktree 的 remote ref 会互相污染）
- `--force-with-lease` 优先于 `--force`
- 每个接线 PR：三重门（GNU oracle / ctest base / 旧 exe 逐字节）+ i18n baseline 记账
- 多分支并行时：worktree 可能被他人切分支——动手前 `git status` + `git branch --show-current` 确认
