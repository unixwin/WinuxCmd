# sed 命令

## 状态

**Partial / Tested**。WinuxCmd 已覆盖一组经过回归测试的 GNU sed 脚本命令和地址形式，但尚未宣称完整 GNU sed 语言兼容。

## 已测试的脚本子集

- 替换：`s///`，包括 `g`、`p`、忽略大小写、数字 occurrence、反向引用和 `w`
- 文本与输出：`a`、`i`、`c`、`p`、`P`、`=`、`l`、`F`
- 流程控制：`d`、`D`、`n`、`N`、`q`、`Q`、`b`、`t`、`T`、标签、hold space 命令
- 文件命令：`r`、`R`、`w`、`W`
- 地址：数字、末行、正则、范围、否定、步长和分号分隔命令
- 输入模式：`-e`、`-f`、`-n`、`-E`、`-z`、`-i`

完整 GNU 脚本语言仍需通过差分测试继续核验；未覆盖的语法不能仅因为解析器接受而标记为 Done。
