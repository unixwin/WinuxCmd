## 0. 换装定义（2.0.0 的 Done 判据）

**"正式换装" = 以下九条全部成立：**

1. **清点归零**：`DOCS/2.0-inventory.tsv` 176 applet 每行 ∈ {`rust2-wired`, `retired(注记原因)`, `deferred(issue 号)`}——零 `c++-only`。
2. **C++ 体退役**：`src/commands/` 只剩 (a) 显式保留面（grep -P/PCRE2 等，有 decision doc 锚点）、(b) REGISTER_COMMAND 注册壳、(c) 豁免清单（每条一个 issue）。1.x 主体代码从构建中消失。
3. **I18N 清零**：全部用户可见消息 tr! 稳定 key；zh-CN catalog 同步（VERSION 联动）；i18n-drift CI 绿。
4. **差分门全量**：每接线命令 ≥N 行 gate（N=该命令语义面议，大件 ≥140），rust2-gate CI job 覆盖全语料；GNU oracle 差异逐条 triaged（compat-gap / noise-platform / wording，零 untracked 差异）。
5. **ABI/FFI**：输出状态归属裁定落地（host_v4）；FFI 产品路径门①③解红，或 #1487 以正式裁定关闭（deferred-with-verdict，非搁置）。
6. **locale 值模型**：#1549 的 locale-database 模拟层落地，keyword_value() 值表退役。
7. **性能闸**：baseline-growth 绿；无对 C++ 1.x 的 >1.5x 回归；已知差距（sed -n /re/p DFA）有 issue 跟踪或修复。
8. **打包**：default/full edition 命令面审计定稿；installer；release notes（中英）；wpm-source 索引更新 job 恢复常态。
9. **发布**：2.0.0 tag + 迁移指南 + 公告。旧 1.x 行为差异以 DOCS 兜底（migration guide 逐命令对照表）。

## 2. 全局纪律（所有 WP 默认生效，不再重复）

1. **开工三步**：`git fetch origin` → rebase origin/main → `git worktree add D:/repo/<自己的树> origin/main -b <分支>`。目录已存在就报告不要抢。
2. **Ctx 禁令**：rust2 测试/新代码禁止 `Ctx { .. }` 结构体字面量（E0063 事故）——`Ctx::new(cwd, &env)` / `Ctx::with_host(...)`。
3. **I18N 前置**：新用户可见消息一律 tr! 稳定 key（`command.<cmd>.error.<what>` 风格、具名占位符、`{{ }}` 转义、GNU error() 内层措辞 fallback、程序名前缀留代码）；`scripts/i18n_batch.py extract/validate` 过；catalog 配套提交放 `D:/repo/winuxcmd-i18n`（独立 commit、VERSION 按 check-version-bump、**不 push**，报 commit 号，captain 排时序）。
4. **探针**：agent bash 是 niubash 系，`MSYS_NO_PATHCONV` 无效；GNU oracle 一律 WSL **脚本文件**（禁 `wsl bash -c "引号串"`）；PowerShell 原样交接用于产品面；fixture 往 sh 脚本嵌路径一律正斜杠（MSYS2 sh 吃反斜杠）。见 rust2/gate/PROBE-METHODOLOGY.md。
5. **提交纪律**：agent 不 commit 不 push；报告文件清单+验证原始数字，captain 审后分组提交（照 #1660 形态：库修复/接线/门/测试/docs 拆组）；PR 措辞 **Fixes 自动关 issue，Refs 由 captain 手动关**。
6. **红线**：永不添加 `link` 命令（CMake WINUXCMD_BANNED_COMMANDS）；禁真实根递归探针；禁未隔离全量 ctest；测试只在临时 shell-root/临时目录；本地构建过再交（gate 用 driver 前先 build driver，防陈旧二进制假绿）。
7. **撞车**：认领 issue 先评论 claiming；worktree 目录冲突报告不硬抢；不动 captain 的在飞面（#1660/#1659、i18n 未推提交、wc-docs）。
8. **合并前全量**：wire 类 PR 合并前 captain 跑全量 lib test（双 PR 语义冲突教训：#1636×#1625）。
