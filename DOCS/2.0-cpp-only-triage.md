## 1. 分类判据（本文实际使用的口径）

| 类别 | 判定规则 | 本文使用的锚点 |
|---|---|---|
| **A. 该做** | inventory `anchor` 只有 `#1488 (waveN)` 排期，没有“不做/保留/退役”的反证；命令用户可见、属于 GNU/util-linux/procps/findutils 等常驻命令面 | `DOCS/2.0-inventory.tsv` 的 `anchor` 列；`DOCS/2.0-MASTER-PLAN.md` §0/§5.I/§5.J |
| **B. deferred 有据** | anchor/issue 明确写了暂不做或回退的**原因**；保持 `deferred(issue 号)`，不臆造进度 | `#1757` / PR `#1795` / commit `55d85ba8` |
| **C. retired** | 命令级退役（从命令面移除）或被其他命令取代；选项级退役不算 | `DOCS/2.0-MIGRATION.md` §3（只列选项级）；`DOCS/2.0-inventory-summary.md`（`retired = 0`）；`AGENTS.md` Banned commands |
| **D. 保留面** | 平台专属能力或 WinuxCmd 自有桥接面；decision/audit 文档明确“不裁/保留/仅 full edition”，不做 1:1 GNU 机械替换 | `DOCS/2.0-MIGRATION.md` §2/§7；`DOCS/2.0-regex-engine-decision.md` §6；`DOCS/2.0-edition-audit.md` §4.2/§4.3；`DOCS/en/wpm_guide.md` |
| **已 wired** | 命令名在 `WINUXCMD_RUST2_COMMANDS`，且 `src/commands/<cmd>.cpp` 调 `winux::rust2::run_command` | `CMakeLists.txt` + 接线 commit |

**关于 `#1488`**：`#1488` 是“2.0 命令库化”的总 epic，`wave2/3/4` 只是排期，不是“不做的理由”。因此本文不把 `#1488 (waveN)` 当作 B 类依据；否则 94 条几乎全会被错误地“deferred 合理化”。

**关于 `link`**：`AGENTS.md`「Banned commands」明确永不添加 `link`（MSVC `link.exe` 冲突，`WINUXCMD_BANNED_COMMANDS`）。它不是 176 applet 之一，所以 94 条里没有 `link` 行；C 类因此为 0，而不是漏判。

## 4. C 类为什么是 0

- `DOCS/2.0-inventory-summary.md`「2.0 终版清点」明写：`retired(…) = 0`，「当前没有任何命令级退役；退役面全部是选项级扩展」。

- `dir`/`vdir` 是 ls 的独立注册别名、`d2u`/`u2d` 是 dos2unix 套件别名，但 GNU/dos2unix 上游仍提供这些名字，属于“别名/桥接面”，不是“被其他命令取代后退役”；分别归 A（需与 ls 同批）和 D（桥接面）。
