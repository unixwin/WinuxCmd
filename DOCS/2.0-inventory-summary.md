# WinuxCmd 2.0 命令库化 —— 第一步清点扫描小结（#1488 step 1）

数据文件：[`docs/2.0-inventory.tsv`](./2.0-inventory.tsv)（176 行 + 表头）。
本文件是按 #1488 要求对该表的解读小结。扫描只清点、不改任何源码。

## 方法与口径

- **applet 清单**：以 `src/commands/*.cpp` 的 `REGISTER_COMMAND` 宏为权威（每文件一注册，`cmd_name` 字符串为命令名，含 `[`，无重名）。扫得 **176 个**；#1462 写"178 applet"与本表差 2，以宏扫描为准，差异可能来自该文书写时点或别名计数口径。
- **loc**：`wc -l` 原始行数（含注释/空行），便于跨命令比较，非净代码行。
- **io_idiom**：对剥离注释后的源码做正则归类，五个原始类别：`iostream`（std::cin/cout/cerr）、`crt-stdio`（fgets/fprintf/fread/fwrite/printf/puts/fopen…，含 `stdin/stdout/stderr` FILE\* 流）、`read-all-stdin`（file_io::read_all_stdin）、`win32-console`（safePrint/safeErrorPrint\* 包装，即 utils/console.cppm 的 Win32 句柄层）、`win32-direct`（命令代码直调 GetStdHandle/ReadFile/WriteFile/WriteConsole…）。单类别记单值；≥2 记 `mixed(...)` 并列明组合。
- **global_state**：`thread_local`、可变 `static`（static_cast/assert/const 不计）、`setlocale/_setmode/locale`、`errno`（注释提及不计）、文件级可变全局缓冲。
- **exit_usage**：`exit/_exit/abort/ExitProcess/TerminateProcess` 等（注释不计）。
- **oracle_status**：解析 `tests/differential/audit-*.md`（#1462 各轮审计报告）逐命令归属：在 Verified-clean/PASS/MATCHES 清单 → `audited:clean`（含 near/minor 限定条目）；带 [BUG]/FAIL/DEVIATES 判定 → `audited:deviates`；仅被提及无明确判定 → `audited:notes`；报告完全未提及 → `unreviewed`；#1462 W8 裁定的自有面（wpm/cygpath/regtool/dos2unix 族）→ `no-oracle(...)`。
- **test_coverage**：`tests/unit/<cmd>/` 存在记 `unit`；`tests/differential/corpus/<cmd>/` 存在记 `differential:N`（N=用例数）。
- **replace_wave**：机械规则（简单度 × 频率）：纯单习语 + 无全局状态 + 无 exit + 高频 → wave1；其余按有/无轻度状态（errno、单 static）与频率落入 wave2/3；引擎级/交互式/常驻 TUI（sed/grep/find/less/more/top/watch/ps/stty）恒为 wave4。频率分级为人工判断（HIGH≈cat/echo/ls/cp/mv/rm/sort/grep 等日常高频；MED≈od/join/base64 等）。

## 最难的五个命令（建议最后替换）

| 命令 | loc | 难点 |
| --- | --- | --- |
| find | 5578 | 全仓最大引擎：CRT stdio + iostream + console 三系并存、static-mutable、递归遍历状态机与谓词求值耦合 |
| grep | 3096 | 四类 IO 习语并存（含 Win32 直调）、static-mutable、正则引擎 + 上下文输出缓冲，差分门 15 用例最重 |
| sed | 2802 | iostream + console + Win32 直调，脚本编译/执行两态、hold space 等会话内可变状态，deviates 待修项多 |
| top | 1551 | 常驻 TUI：CRT + 直调句柄 + static-mutable + TerminateProcess，interval 刷新与终端几何强耦合，平台非确定性 |
| less | 1187 | 交互分页器：iostream + 直调句柄，键位会话状态、终端原始模式控制，库形态需整层会话抽象 |

次难（同层，未入前五）：stty（console mode 直调、终端属性会话语义）、watch（top 的子集）、ps（进程枚举平台面）、ptx/pr/cpio（大而旧的文本/归档管线）。

## 建议第一批替换名单（wave1，15 个）

入选标准（全部满足）：唯一习语或无 IO、零全局状态、零 exit 直调、oracle 已审（pwd 除外）、unit+differential 双覆盖。

true、false、test、[、basename、dirname、printenv、pwd、mkdir、rmdir、readlink、realpath、chmod、chown、df

理由：这 15 个是「机械替换」风险最低的集合——输出全部走 safePrint\*（true/false 连输出都没有），替换成显式 IO 参数的库函数时不需要处理环境 stdio 绑定；global_state 与 exit_usage 全空，行为面即纯函数；13/15 已在 #1462 审计中判 clean（chmod 为 deviates，替换时顺带继承审计分歧清单）；且全部高频或核心文件面命令，替换后由 rubash/niubash 差分门立即回归。df 体量最大（1417 行）但 IO/状态面同样干净，可作第一批收官件。

次批候选（wave2 中条件最好的）：whoami、nproc、unlink、sleep、base64、base32、b2sum、sha224sum、sha384sum、tac、truncate、uname、id、hostname、getconf——同为纯 console 习语，仅带轻度 errno。

## 抽查校验与误分类率

人工读源码核对 7 个扫描结果：df（clean ✓）、hostname（exit 全在注释 ✓）、tr（thread_local/全局缓冲/CRT fwrite 全实 ✓）、cat（mixed 三系 ✓）、kill（TerminateProcess×7 ✓）、sync（无输出调用 ✓）、mkfifo（**初判 io=none 为误**：`safeErrorPrint` 无 Ln 后缀漏匹配，修正正则后为 win32-console ✓）。

误分类率：初扫 1/7（14%），定位为扫描器 `safeErrorPrint` 漏匹配并已修正，修正后复核 7/7 一致。残余已知偏差：`audited:clean` 未区分 near/minor 限定词；io_idiom 对「注释外仍可能被宏展开引入」的习语不敏感（如经 pipeline 辅助的隐式 IO），替换开工时以逐命令人工复核为准。
